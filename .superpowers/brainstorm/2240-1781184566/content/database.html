数据库表设计

第一期核心表

schools · 学校
id / name / 其他配置
colleges · 学院
id / school_id / name / grade_levels
users · 用户（统一表）
id / role(学校|学院|企业|学生) / college_id
name / phone / password / status
enterprises · 企业资料
id / user_id / name / credit_code / industry / scale
contact_name / contact_phone / email / intro / college_id
enterprise_docs · 审核资质文件
id / enterprise_id / type(执照/身份证/委托书)
file_path / status / reject_reason
students · 学生资料
id / user_id / student_no / class_name / grade
resume_path / college_id(学号自动匹配)
jobs · 招聘岗位
id / enterprise_id / title / count / city / salary_min
salary_max / education / major / skills / type
duty / requirement / welfare / status(上/下)
applications · 投递记录
id / job_id / student_id / status / created_at
student_id_rules · 学号匹配规则
id / school_id / prefix / college_id
messages · 消息（二期）
id / from_id / to_id / content / read_at
💡 设计说明：users 统一登录表用 role 字段区分角色；企业/学生详情用独立 profile 表分开存储
