高校校园招聘平台 — 角色与流程全景

四个角色层级 + 核心审核流程

🏫 学校（超级管理员）
• 管理所有学院
• 审核企业资质（上传营业执照等）
• 批准/拒绝企业入驻
• 平台全局设置
• 查看全平台数据统计
🏛️ 学院（管理员）
• 管理本院已审核通过的企业
• 查看本院学生
• 本院招聘数据统计
• 本院招聘信息分类管理
🏢 企业
• 注册 + 上传资质 → 等待审核
• 审核通过后发布招聘信息
• 浏览学生简历
• 下载/预览简历
• 向学生发送消息
🎓 学生
• 注册 + 填写/上传简历
• 浏览审核通过企业的招聘信息
• 投递简历
• 接收企业消息
• 管理求职状态
企业注册 → 上传资质 → 学校审核 → 通过 ✅ → 发布招聘 → 学生可见 👀
拒绝 ❌ → 退回修改
🔑 核心约束：只有审核通过的企业才能被学生看到
