系统架构 — 前台 + 后台

五个板块，两套视觉风格

🌐 前台（面向学生）
高校招聘门户 · 展示型
• 首页 — 平台介绍 / 统计数字 / 热门岗位
• 岗位列表页 — 搜索/筛选/分页
• 岗位详情页 — 企业信息 + 岗位详情 + 投递
• 企业展示 — 已审核企业列表/详情
• 学生注册/登录
• 学生个人中心 — 简历管理 / 投递记录 / 消息
🔧 后台（管理型）
三个独立管理面板
🏫 学校后台
学院CRUD / 企业审核 / 学生管理(筛选+搜索) / 学号规则 / 数据统计
🏛️ 学院后台
本院企业 / 本院学生 / 数据统计 / 与学生沟通
🏢 企业后台
审核进度(未审核) / 岗位管理 / 简历浏览下载 / 与学生沟通
路由
/ 前台门户
/jobs 岗位列表
/student 学生中心
路由
/enterprise 企业后台
/admin/college 学院后台
/admin/school 学校后台
技术
前台：Vue 3 + Tailwind
后台：Vue 3 + Tailwind
API：Laravel 12
