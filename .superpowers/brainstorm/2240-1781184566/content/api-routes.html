API 路由设计

Laravel API 路由 · 第一期全部端点

Auth · 认证
POST /api/auth/login
POST /api/auth/logout
POST /api/auth/register/student
POST /api/auth/register/enterprise
GET /api/auth/captcha
GET /api/auth/me
Jobs · 岗位（公开）
GET /api/jobs
GET /api/jobs/{id}
GET /api/enterprises
GET /api/enterprises/{id}
Student · 学生
POST /api/student/resume
DELETE /api/student/resume
GET /api/student/applications
POST /api/student/jobs/{id}/apply
PUT /api/student/profile
PUT /api/student/password
Enterprise · 企业
GET /api/enterprise/audit-status
POST /api/enterprise/docs
DELETE /api/enterprise/docs/{id}
GET /api/enterprise/jobs
POST /api/enterprise/jobs
PUT /api/enterprise/jobs/{id}
PATCH /api/enterprise/jobs/{id}/status
GET /api/enterprise/jobs/{id}/applications
GET /api/enterprise/resumes
GET /api/enterprise/resumes/{id}/download
PUT /api/enterprise/profile
PUT /api/enterprise/password
College Admin · 学院后台
GET /api/admin/college/dashboard
GET /api/admin/college/enterprises
GET /api/admin/college/students
PUT /api/admin/college/students/{id}
DELETE /api/admin/college/students/{id}
School Admin · 学校后台
GET /api/admin/school/dashboard
GET/POST /api/admin/school/colleges
PUT/DELETE /api/admin/school/colleges/{id}
GET /api/admin/school/enterprises
GET /api/admin/school/enterprises/{id}
POST /api/admin/school/enterprises/{id}/audit
GET /api/admin/school/students
PUT/DELETE /api/admin/school/students/{id}
GET/POST /api/admin/school/admins
PUT/DELETE /api/admin/school/admins/{id}
GET/POST/PUT/DELETE /api/admin/school/student-id-rules
PUT /api/admin/school/settings
中间件策略：
• auth:sanctum — 所有需登录的路由
• role:school|college|enterprise|student — 角色中间件
• enterprise.status:approved — 企业功能需审核通过
• API 统一返回格式： {"code":200,"message":"success","data":{}}
